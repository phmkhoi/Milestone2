We proposed \method, a multi-view transformer model for 3D object manipulation. We found that \method outperforms prior state-of-the-art models like PerAct and C2F-ARM on a variety of 3D manipulation tasks, while being more scalable and faster. We also found that \method can work on real-world manipulation tasks with only a few demonstrations. 

Although we found \method to achieve state-of-the-art results, we identify some limitations that present exciting directions for future research. We briefly explore various view options and found an option that works well across tasks, but it would be exciting if view specification can be optimized or learned from data. Further, when compared to prior view-based methods, \method (as well as explicit voxel-based methods like PerAct and C2F-ARM), requires the calibration of extrinsics from the camera to the robot base. It would be exciting to explore extensions that remove this constraint.
