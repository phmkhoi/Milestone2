\section{Conclusion}

We present Citadel, to our knowledge, the first enclave platform with strong microarchitectural isolation on a speculative out-of-order multicore processor. We develop a new hardware mechanism for secure shared memory and provide a full end-to-end implementation of our platform.
Our prototype runs on FPGAs and boots untrusted Linux from which user-level applications can run secure enclaves.
We evaluate our prototype through two realistic scenarios running a cryptographic library and a bare-metal Python runtime inside of an enclave.
