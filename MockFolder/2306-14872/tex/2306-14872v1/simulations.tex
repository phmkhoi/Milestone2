In this section, we present the simulation results of TS-MR, Greedy-MR, and other baseline algorithms. 
\paragraph{Example 1. Stochastic linear bandit with uniformly and independently distributed actions.} We fix $d = 50$, and sample $\param\sim\text{Unif}(\{\theta \in \mathbb{R}^d|\|\theta\|= 10\}) $ on a sphere with fixed norm. At each time $t$, we generate 100 i.i.d. random actions sampled from $\text{Unif}(\cS_{d-1})$ to form $\cX_t$. This is a basic example of standard stochastic linear bandit problems without any extra structure. We set the threshold  $\mu = 8$ for TS-MR and Greedy-MR. We average simulation results over 20 independent runs. The results are summarized in Figure~\ref{fig:ex1}. TS-Freq shows pessimistic regret due to the inflation of the posterior, while other algorithms in general perform well. 



\paragraph{Example 2. Contextual bandits embedded in the linear bandit problem  \citep{abbasi2013online}.} We fix $d = 50$, and sample $\param\sim\text{Unif}(\{\theta \in \mathbb{R}^d|\|\theta\|= 70\}) $. At each time $t$, we first  generate a random vector $u_t \sim \cN(0, \II_5)$ and let $x_{t,i}\in \RR^{50}$ be the vector whose $i$-th block of size 5 is a  copy of $u_t$, and other components are 0. Then $X_t = \{x_{t,i}\}_{i\in [10] }$ is an action set of size 10, sharing the same feature $u_t$ in different blocks. This problem is equivalent to a 10-armed contextual bandit. We ser $\mu = 12$ for TS-MR and Greedy-MR. Again, we average simulation results over 20 independent runs. The results are summarized in Figure~\ref{fig:ex2}. In this setting, Greedy performs suboptimally due to a lack of exploration for all arms. Nevertheless, Greedy-MR outperforms both Greedy and OFUL by adaptively choosing OFUL actions only when it detects bad regret ratio $\hat{\mu}_t$.  



\paragraph{Example 3. Prior mean mismatch \citep{hamidi2020frequentist}.} This is an example in which LinTS is shown to incur linear Bayesian regret. We sample $\theta^\star \sim \cN(m \mathbf{1}_{3d}, \II_{3d})$ and fix the action set $\cX_t = \{0, x_a, x_b\}$ for all $t\in[T]$, where $x_a = - \sum_{i=1}^{d} \frac{e_i}{\sqrt{3d}},  \quad x_b = \sum_{i=11}^{3d} \frac{e_i}{\sqrt{3d}}  - \sum_{i=1}^{d} \frac{e_i}{\sqrt{3d}}$.
It is shown in \cite{hamidi2020frequentist} that, when LinTS takes a wrong prior mean as input,  it has a large probability to choose  $\tilde{x}_2 = 0$, conditioned on $\tilde{x}_1 = x_a$. Note that choosing the zero action brings no information update to LinTS, it suffers a linear Bayesian regret when trying to escape from the zero action. We let $m = 10$ and set $d = 10$, so the problem is a $30$-dimensional linear bandit. We ser $\mu = 12$ for TS-MR and Greedy-MR. We carried out 20 independent runs. The results are summarized in Figure~\ref{fig:ex3}. We see both LinTS and Greedy incur linear regrets as expected, while TS-MR and Greedy-MR, switch to OFUL adaptively to tackle this hard problem  and achieve sublinear regret.
